One Wi-Fi network name, 26 characters, that tells a whole breakup in a single breath:

> SheLeftTheRouterTookTheCat

She left, took the cat, and left the router behind — the whole story
is in the name.

`main.py` (Python 3.13, standard library only) writes that fixed name to
`/output/entry.txt`. Deterministic, no network.
